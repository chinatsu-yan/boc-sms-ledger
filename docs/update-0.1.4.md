# 0.1.4 原生四屏与还款日期

基于 fe2003a（0.1.3/code4），保留两个设计提交的历史。在独立 feature/debit-first-ui 分支实现原生 View 四屏：概览、借记流水、信用卡、日期与账本设置。雾蓝与暖砂配色、大数字、独立账户模块，使用原有 Kotlin/SQLite，无新框架或权限。原生控件与设计稿并非逐像素相同，小屏允许滚动，底部导航在内容之外。

首页统计仅借记卡已确认用途的收入/消费，按短信接收日期提供本月与全部范围，逐币种展示。转账、还款本金和待确认用途不并入经济收支；点击收入/支出进入该范围明细。所有原始来源、人工修正、关联与审计入口保留。

余额不通过收支差推算。按既有账户标识（类型/卡尾）及币种，选最近接收且有已确认币种余额的短信快照。同一账户币种只取一条；排除未核对来源和排除记录。界面显示每个账户快照及接收时间；有任一已知账户缺快照，该币种总余额显示未知，并标覆盖数。完全没有识别账户也显示未知。短信可能延迟或不完整，因此明确称“最近接收的可用快照，非实时余额”。既有账户模型只保存卡尾，不具备同尾号实体卡消歧能力。

信用卡保持原历史交易日折 USD、最新 USD/CNY 估算、覆盖数、缺汇率状态及点击查看来源/有效日/获取时间的明细。原币列表、过滤、退款关联和还款本金排除仍使用原逻辑。

设置页分开配置账单日和还款日，后者包括出账当月/次月与 1–31 日；短月分别夹到月底，预览当前所选账期对应日期。同月日号早于账单日不允许保存。修改账单日使旧还款规则冲突时，提示重新配置。旧版本没有 repayment_day，升级显示未设置，不写默认值。手机与演示配置分别保存在原 billing / billing-demo 中。没有新增通知权限、提醒或后台定时任务。

数据库表结构和版本不变。只改 UI、增加纯计算模型与独立偏好字段；解析、短信任务和汇率仓库未改。包 local.boc.ledger，0.1.4/code5，min26/target35，原 debug 签名。覆盖安装，不要卸载或清数据。
