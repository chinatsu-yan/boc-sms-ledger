# 0.1.10 — 借记卡收入识别

版本0.1.10/code11，基线ed7044f。同包local.boc.ledger、同debug签名。

原因：旧模板只接受“收入(网银跨行)”一个固定渠道，而且金额与余额之间只接受英文逗号。带“收入(公积金)(提取托付)”和中文逗号的真实格式因此未被识别，按既有规则不显示在主流水。

修复：借记卡收入支持一个或多个括号说明段，保留原渠道（例如“公积金 / 提取托付”），兼容中英文逗号。仍严格要求完整收入模板、人民币金额与余额，不从任意文本中截取金额。识别为借记卡资金转入，进入首页资金收入；经济用途仍待确认，不自动判为工资或消费。

解析版本4，账本数据库升至v3。首次打开旧账本时，仅重新识别旧版未识别、未人工修改、未排除且没有关联的借记卡收入记录；保持原行ID、短信、来源和类别，留下升级识别审计。人工修正和关联不覆盖，后续扫描仍按原来源幂等。无需重新导入短信。

验证：合成结构用例先在旧版复现失败；修复后18项定向核心测试通过（新收入3、原解析14、资金流1）。测试和文档没有用户真实卡尾、金额、余额或原文。设备升级测试与最终构建结果见交付记录。

安装：覆盖安装，不卸载；打开App即可刷新已保存的这类收入。如记录未曾导入，原有自动扫描与“补读历史范围”继续可用。

交付记录：assembleDebug、assembleDebugAndroidTest、lintDebug通过。API26模拟器同签覆盖安装成功，旧数据升级测试1项通过（4.833秒）：旧未识别收入恢复、年度推断、资金流汇总、人工更正与排除保留、关联保留、重复导入幂等及一次性升级审计。未访问真实手机或短信。
