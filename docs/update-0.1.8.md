# 0.1.8 — 账期流水、有效筛选与短信年份

基线959cc2a（0.1.7），独立fix/ledger-v18-filters-dates分支。包名local.boc.ledger，min26/target35，同debug签名，版本0.1.8/code9。没有新增权限或数据库结构迁移。

## 五项修复

1. 信用卡入口原先只是切换账户类型，未传递账期；“最近流水”也取全部日期。现在信用卡可明确选择卡账户，估算和本期流水使用同一账户、同一交易日期范围。进入流水继承账户及最近还款日对应账期，列表可切换上/下期，返回信用卡时同步所选账期。人民币单列、外币历史美元参考保留。
2. 原账户/币种依靠隐藏Spinner的布局回调刷新，弹层选择后不可靠；分类按钮原本用于批量标记而非分类过滤。现在账户、币种、分类使用独立状态，并在选择时直接重算列表和消费净额。日期统一筛选交易日期，信用卡账期不再拿短信接收日筛选。组合条件同时生效，清除会清掉账户/币种/分类/搜索/日期，并退出账期模式；返回和标签切换保存各自状态。
3. 原规则完全忽略已保存的短信时间，正文无年就一直未知。现在按该条短信时间的北京时间日期，在相邻年份中选择最近且已经发生的月日，处理12月/1月跨年；必须为半年内唯一候选。未来月日更近、时间无效、闰日不明确等情况保留未知。明确正文年份不改，人工字段日期不补。解析原文/原始解析结果不重写；读取既有账本时自动投影推断日期，因此正常升级后即生效，重解析也保留人工字段、分类和现有关联。来源详情注明年份依据。
4. 删除文本下拉符号，使用统一绘制的箭头、固定44dp筛选按钮和同主题选择弹层。筛选值与当前账户清晰显示，选择项高亮。
5. 筛选区采用稳定两列布局，完整日期单独一行；数量/清除/批量对齐。多币种合计移入独立详情，单币种筛选直接显示消费净额。商户与金额分行，长金额自动缩放且币种不丢；去掉自定义控件返回后的方形焦点底色。

## 必要验证

首次核心测试50项通过；最终年份边界调整仅回归SmsDateTest。构建assembleDebug、assembleDebugAndroidTest与lintDebug通过。使用同一API26/390×844模拟器覆盖安装，无卸载清数据。

设备针对性验证：短信跨年推断、原解析年份仍为空、人工日期不覆盖、人工分类与既有关联在重解析后保留；信用卡账户/账期继承与切换返回；账户、币种、分类组合筛选、空结果、清除、详情返回保留筛选；通过日期选择弹层设置单日范围；原币/美元参考与长金额实际展示。截图只含合成数据。

未访问真实手机、真实短信；未新增多设备或Android15测试。没有全库校验或重复跑旧交互矩阵。无法确定年份的记录仍在全部日期视图可见，限定账期时不猜入账；推断日期不是银行官方入账日期。

## 安装

直接覆盖安装0.1.8，不卸载旧版。信用卡选择账户后点“查看本期流水”；日期栏箭头切换账期，“自选日期”切换到日期筛选。流水可按账户、币种、分类组合；“清除筛选”恢复全部日期与全部账户。既有短信缺年展示自动更新，无需重新导入。
