# 0.1.5：修复用户验收的四项问题

基于 03ba68a / 0.1.4，在 fix/ledger-v15-feedback 独立分支修复。包 local.boc.ledger，versionName 0.1.5 / code6，min26 / target35，同 debug 签名。不增加权限，不改变账本表结构。

## 1. 首页收入/支出

修前：使用经济分类汇总，而三类已识别借记模板默认用途待确认，因此全部被经济收支报表排除；默认本月也会排除更早接收的历史短信。

修后：首页默认全部已导入，可切换本月；注明接收时间范围。按事件方向统计借记卡资金流：跨行收入为流入，网上支付/跨行支取为流出。无需先人工分类，转账与还款可以反映在已识别借记流水的资金流中，但不称消费。信用卡消费及信用卡购汇还款事件不混入。经济分类与原始事件不改；未识别、未确认来源、排除的记录不计。按币种分开统计；点击金额进入该范围对应方向明细。

没有匹配记录时说明范围原因并提供切换全部或扫描设置入口。余额仍独立来自各账户/币种最近接收的可用短信余额快照，缺失未知，不以收支相减推算。

## 2. 界面

修前：系统 Button 列表、全局授权/状态占据首屏、估算文本墙，与设计稿结构差异明显。

修后：按 debit-first-v2 的雾蓝/暖砂、无卡片顶部收支与大号余额、暖砂借记模块、深蓝信用模块、自绘统一线性导航图标实现。工具退到右上角与设置页。借记流水改为日期/名称/原币金额/状态的对齐行；信用卡以大号 USD、人民币估算、覆盖卡片、待关联入口和还款时间线组织。日期设置单独呈现日号、月份规则与预览。采用原生 View，无远程 Web 页面。

## 3. 默认账期

修前：总是 BillingCycle.containing(today)，即正在积累消费的账期，与下次还款对应账期不同。

修后：配置有效还款规则后，枚举相邻账单月份，选择还款日在今天或最近未来的账期。还款当天仍属于该期，次日自动切下一还款期。支持出账当月/次月、短月夹到月底、跨年与闰年；上/下账期仍可手动切换。未设置或规则冲突时清楚提示并保留账单周期选择，不能冒称银行已出账。设置对话框按候选新规则实时预览。

## 4. 自动关联与快捷人工处理

新增保守自动关联：已确认来源、币种明确、同卡尾账户、同币种、完全相同且非空商户，正文日期完整，调整不早于消费且在30天内、非未来日，金额不超过原消费，候选必须唯一。仅在这些条件全部成立时自动关联；同金额但没有商户的成功退货短信不自动猜。支持全额/部分及提供方先收到调整、后收到消费，累计冲减不超额。消费和调整分别保存，不删原文。

自动关联发生于批量补扫后与账本刷新时，按演示/正式来源与 SIM 分组。不修改人工修正记录，不替换已有关联；所有动作写审计。用户手动解除后，该调整不再自动绑定，仍可主动手工重新关联。重解析继续冻结已有相关证据，补扫与重复运行幂等。

信用卡页提供“待关联 N · 撤销/退货”按钮，进入原文/候选和人工关联，关联后可从交易详情解除。无商户、多个候选、缺原交易或超额保持待关联，不强迫处理。现有七类模板没有交易编号字段，不假造编号匹配。
