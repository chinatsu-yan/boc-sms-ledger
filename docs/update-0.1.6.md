# 0.1.6 — clear-ledger-v3 原生实现

基线 cf31853（0.1.5），视觉依据 e0a398b 的六屏稿；独立 feature/clear-ledger-v16 分支。版本0.1.6/code7，同包 local.boc.ledger，min26/target35，同debug签名。没有增加权限，没有云同步、AI分类、新银行或导出备份。

## 已实现

- 概览、流水、统计、信用卡、核对关联、分类规则六页。暖白底、青灰数字、暖砂借记卡、深青信用卡、统一线性图标；说明移入详情/工具，底部五项导航。金额按币种分开，余额仍为每账户最近有依据的短信快照。数据为空不会编造余额。
- 流水单条分类、批量选择/分类/保存/取消；餐饮、购物、交通、日用、订阅、其他，可新增自定义类别。搜索原文/商户/金额，账户/币种/接收日期筛选。
- 商户原始名称精确匹配，显示别名和默认类别；规则默认只用于之后导入记录，勾选才套用既有未分类记录。人工类别及字段修正优先；重解析不覆盖。删除规则不抹去旧标签。
- 分类环图、类别排行、分段趋势由账本精确金额计算。借记统计按接收日期，信用卡按完整正文交易日期；账户和原币明确选择，日期不全信用消费保留待确认入口。按原消费归属净额，已关联且日期有效的退款撤销扣一次，转账/还款不算消费。网上支付未分类仍在“待分类”；用途不明的跨行转出单独提示，不默认为消费。
- USD/CNY参考折算继续位于信用卡页，不与原币分类图混算。显示报价覆盖，缺率显示“—”，详情保留来源、有效日期、缓存和未覆盖原因。示例账本不联网，截图人民币估算缺失如实显示。
- 信用卡仍默认今天或最近未来还款日对应账期；配置当月/次月还款，短月取月底，冲突提示，提醒不自动启用。

## 关联

同账本/SIM、同卡、同币种、原始商户非空精确相同、金额数值相等、完整正文日期不晚于调整时，自动选择最早尚有足额可冲减空间的原消费；相同日期按稳定本地记录ID排序。七种模板没有时分/交易编号字段，不伪造更细时间。取消旧30天和唯一候选限制。

无商户仅同额不自动；部分退款由“其他金额”人工选择。默认人工候选同额且余额够用；过滤跨卡/跨币种/跨来源，正文完整日期可判定时禁止调整关联之后的消费。日期未知人工核对，页面直接展示双方原文、卡、金额、日期和商户。确认/解除写审计，已有关联不重配；明确解除阻止后续自动绑回。先收到撤销、后导入消费可补扫关联。原始事件不删除。

45项核心测试通过；原13项设备数据测试通过，新增3项分类/迁移测试通过（其中最终待分类重置规则单独回归），另有真实既有账本升级对比。构建assembleDebug、assembleDebugAndroidTest、lintDebug成功；lint零错误、4项警告（图标绘制分配2项、仅程序构建View的XML构造器2项），以生成报告为准。

设备六屏流程覆盖：单条分类取消与保存、批量分类保存/退出、统计展示、待关联入口与原文、人工关联确认、重解析/解除后不重绑、自定义输入取消、演示/手机账本隔离。软件模拟器API26，390×844默认字体及320×640/1.3倍字体；实际截图已对照六屏稿。通过触摸滚动检查内容与固定底导航，输入法弹出时确认/取消仍可见。

未测试真实手机、真实短信或Android15显示；不声称已覆盖所有厂商后台行为。自动扫描、币种、历史汇率相关既有测试保留。没有推送、合并或发布release。

## 使用

覆盖安装，不要卸载。流水点类别，或“批量”选择后标记；统计选择账户、日期、原币。设置中添加商户规则/自定义分类；原文缺商户时可先在原有字段修正中补充，不能凭渠道猜。信用卡“撤销/退货待关联”进入双原文核对，部分退款切“其他金额”。已关联记录从交易详情可解除。
