# 0.1.11 — 收入分类与统计

版本0.1.11/code12，基线ece998d，同包同debug签名。

原先流水分类按钮与数据库分类逻辑只允许支出，统计也只读取消费净额；现在借记卡收入可点分类标签直接选择保存，无须字段修正。支持收入批量分类、取消选择，以及工资、奖金、公积金、利息、其他收入与自定义收入分类。收入/支出分类分开维护；混合方向请分开批量处理，避免把流入标成消费。

统计页在同一日期、账户、原币筛选下显示收入/支出总额，点对应金额切换分类环图、排行和时间趋势。未分类收入保留在待分类组；已标转账、还款或其他非收支不计入收入分类统计。信用卡退款、撤销、还款不会被当成收入，支出继续采用关联调整后的消费净额。首页仍为借记卡资金流入口径，包含转账，与分类统计口径分开。

收入分类保存在原有人工标签中，类别设为INCOME，重解析不覆盖；数据库v4仅新增income_categories表与默认分类，不重建账本。已识别收入无需重新扫描或导入，升级后即可分类。原有分类、关联、账户及汇率能力保留。

验证使用合成数据。核心测试覆盖待分类收入、转账排除、信用卡调整排除、币种与筛选分离，以及既有支出净额。设备检查覆盖v3升级、旧分类保留、收入单笔/批量/自定义、重解析、转账切换与图表；实际界面图仅保存工程验证记录。没有读取真实手机或短信。

交付记录：7项核心测试、6项定向设备测试通过；针对收入UI补拍时单独重跑该交互1项通过（49.032秒）。首轮截图被模拟器System UI弹窗遮挡，关闭后重新拍摄并实际查看320×640的分类弹层、收入统计和趋势三张图，无遮挡或金额截断。构建assembleDebug、assembleDebugAndroidTest与lintDebug成功；覆盖安装不卸载。
