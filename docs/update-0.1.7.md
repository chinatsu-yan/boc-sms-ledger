# 0.1.7 — 币种分区与返回层级

基线 676ab37 / 0.1.6。独立 `fix/ledger-v17-navigation-currency` 分支；包名 `local.boc.ledger`、minSDK26、targetSDK35 保持，版本0.1.7/code8。无数据库迁移和新增权限。

- 标题栏固定，底部导航保留；金额与商户对齐，信用卡汇总改为外币参考与人民币单列两部分。流水金额直接显示 ISO 币种，外币下行显示按交易日历史报价换算的美元参考，USD不重复显示，缺率/日期不全短提示。
- CNY（含解析器规范化后的 RMB/人民币）消费及其已关联退款，只在人民币部分计算，不进入 USD 或外币参考 CNY 合计。保留原金额精度，界面参考值显示两位。仍按短信明确币种，不能从一笔外币短信推断银行最终以人民币结算。
- 一级非首页返回首页；内部跳转保存上一页筛选与滚动；从详情进入关联后可回详情。底部标签保留各页筛选。首页两秒内再次返回才退出。系统返回先收起键盘、弹层，再处理页面栈。
- 分类、搜索、日期、商户规则、编辑与详情等统一底部圆角弹层；多层操作取消回到上一层。详情突出金额/商户/分类/原文，来源标识与解析信息收进独立入口。系统短信权限仍由Android提供。
- 自动扫描、关联最早消费、人工修正/分类优先、借记独立收支/余额、原币分类统计和还款日期继续保留。未增加云同步、新银行或其他扩展。

## 验证

核心48项测试通过（含新增人民币退款单列、禁止CNY查询、历史参考方向/三位小数、缺率与日期未知）；assembleDebug、assembleDebugAndroidTest、lintDebug成功，lint零错误。仅使用一台API26/390×844模拟器；同签覆盖安装，无卸载或清数据，既有手工分类保留。新针对性设备流程检查信用卡原币/USD、人民币单列、主次返回、标签筛选、弹层返回、双击退出，实际截图见 `docs/screenshots-0.1.7/`。

未在真实手机、真实短信或Android15设备上验证。历史行情来源继续为Frankfurter，缺失不记0；本次设备参考报价为明确标注的合成数据，没有新增实际外部行情查询。

## 安装

直接覆盖安装0.1.7，不卸载旧版。信用卡“人民币消费”单列；“外币消费”的人民币数只是参考估算。流水中点击美元参考可看报价日/来源。还款设置沿用旧值，无需重新配置。
