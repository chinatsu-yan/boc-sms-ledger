# 本地记账页面提案与还款日设置

本目录是独立静态设计交付，不改 Android 生产代码、数据库、权限或 APK。新增概览样式、还款日配置与提醒均为规划；日期、卡尾、商户、金额和行情全是合成示例，不代表真实用户设置或公开实时行情。未发布网站，未创建提醒。

## 页面与文件

- `boc-ledger-design-overview.png`：四屏总览，3760px 宽。
- `boc-ledger-overview.png`：概览，月度参考合计、借记/信用卡入口、扫描状态和最近交易。
- `boc-ledger-credit.png`：信用卡，账期、历史原币折美元合计、最新美元折人民币估算、覆盖数、还款日期、汇率信息。
- `boc-ledger-transactions.png`：流水，借记/信用卡切换、原币金额、退款关联与缺汇率状态。
- `boc-ledger-settings.png`：独立账单日、还款月份与日号、日期预览、未启用提醒。
- `boc-ledger-design.html`：自包含设计稿，内嵌字体和图标，无外部资源和网络请求。可在本地浏览器打开。可演示借记/信用切换及日期规则，导航仅定位设计屏；月份和币种筛选只是外观提案，未连接账本。

每屏按 412 × 932 CSS px 设计，PNG 以 2 倍像素导出为 824 × 1864。页面采用暖白、墨绿、浅薄荷色，人民币与美元合计层级突出，交易优先展示原币。提醒开关禁用；“应用到设计预览”只更新本页提示，不保存、不访问账本。

## 还款日规则提案

1. 账单日、还款日分别选择 1–31；还款月份明确选择出账当月或次月。
2. 账期为前次账单日次日至本次账单日，含首尾；账单日当天计入当期。这是按短信交易日期的视图规则，不代表银行实际入账时点。
3. 两类日期遇短月均各自取对应月最后一天；不把 31 日溢出到下个月。
4. 还款日期早于本期账单日时显示错误并禁用应用，不自动猜成次月；同一天允许。具体实际还款日须以用户银行账单为准。
5. 示例选择账单日 22、出账次月 12 日。2026 年 6 月账期是 05.23–06.22，计划还款日为 2026.07.12。示例今天是 06.18，所以还有 24 天。所有数值仅是预览，没有替用户确定真实日期。

## 合成金额核对

信用卡有 9 笔消费，其中 8 笔可换算、1 笔 KWD 2.500 汇率缺失且不计入合计。8 笔净额折 USD 分别为：18.00、20.25、13.20、9.00、12.00、15.00、20.00、20.95，合计 128.40。GBP 20.00 消费关联退货 GBP 4.00 后按示例 1.25 折为净 USD 20.00；退货不作为收入再次计数。本金还款不进入消费。

示例最新 USD/CNY 7.20，128.40 × 7.20 = CNY 924.48。三笔借记消费 24 + 156 + 276 = CNY 456.00；本月已覆盖参考合计 1380.48，覆盖 11/12 笔消费。该示例全部消费在 6 月 1–18 日，因此当前月与当前账期的示例信用消费集合相同。未知金额/缺汇率从未当成零，也没有把跨币种原金额直接相加。

## 复现

在安装了 Python fontTools、Playwright、Chromium 和 Noto Sans CJK 字体的本环境中：

```
python design/mobile-ledger-repayment/generate.py
XDG_CACHE_HOME=/workspace/scratch/design-cache python design/mobile-ledger-repayment/render.py
```

`generate.py` 从本机 Noto Sans CJK SC 字体抽取字符并内嵌为 WOFF。该字体 Copyright 2010–2012 Google Corporation，SIL Open Font License 1.1；完整许可内嵌 HTML 注释并附于 `FONT-LICENSE.txt`。`font-subset.woff` 是生成中间文件，HTML 无需它亦可独立打开。
